# The \(S\)-Kummer space of \(\mathbf Q\)

For \(S=\{2,\infty\}\), this journey certifies

\[
\mathbf Q(S,2)=\langle[-1],[2]\rangle_{\mathbf F_2},
\]

constructs the real and \(2\)-adic local squareclass spaces, and verifies both localization
matrices. The unrestricted \(2\)-adic condition together with the zero real condition cuts out
the one-dimensional kernel generated by \([2]\).

`selmer` has the declared return type `SelmerKernel`; for these complete inputs, its literal
runtime result is the promoted subclass `SelmerGroup`. The example checks that promotion only
after the global Kummer basis, both local spaces, both local conditions, and the complete
relevant place set have replayed as complete.

Run it with:

```bash
uv run python examples/arithmetic/q_kummer_selmer/run.py
```

The checked-in arithmetic witnesses have a portable finite replay path. PARI discovery is not
required to rerun this example.
