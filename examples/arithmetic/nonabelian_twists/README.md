# Finite nonabelian twist classes

Let \(C_2\) act trivially on \(S_3\). This example exhaustively enumerates nonabelian
\(H^1(C_2,S_3)\) as a pointed set of cocycle orbits. Replay produces exactly two classes:

- the distinguished identity class;
- the conjugacy class of transpositions.

There is no vector-space structure on the result. The example does not claim to construct a
twisted model or equations for one.

Run it with:

```bash
uv run python examples/arithmetic/nonabelian_twists/run.py
```

No external backend is required.
