# Aim a cocycle

This is the reserved 0.2 user journey. It solves two exact affine aiming problems over
\(\mathbf F_2\):

1. a consistent target with a checked representative and a one-dimensional homogeneous
   family;
2. an inconsistent target with a checked left-nullspace separator.

Both results replay their finite receipts, verify their central certificates, and contribute a
computed node to one claim graph. The obstruction is mathematical data, not an exception or a
message copied from a solver.

Run it with:

```bash
uv run python examples/arithmetic/aim_a_cocycle/run.py
```

The example writes no files and needs no external backend.
