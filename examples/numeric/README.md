# Numeric-to-exact journeys

These backend-free 0.4 journeys exercise the complete bounded bridge rather than isolated API
calls:

- [`two_sheet_cover`](two_sheet_cover/) separates validated numerical branch data from an exact
  Nielsen-vertex binding, then replays the normalized quadratic (B_2) coefficient homotopy;
- [`sqrt2_exactification`](sqrt2_exactification/) separates a bounded recognition candidate from
  independent exact substitution; and
- [`weighted_braid_plan`](weighted_braid_plan/) separates an exact minimum-cost finite-action
  proof from a numerical continuation endpoint.

Every example verifies its portable certificate and claim graph. Deliberately damaged labels,
candidate evidence, or receipt bytes are rejected rather than downgraded to an unexplained
boolean.
