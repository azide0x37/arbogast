# Exact deformation spaces

This portable journey starts from a three-term complex over \(\mathbf F_3\) whose gauge, tangent,
and obstruction spaces are each one-dimensional. It then:

- applies an explicit framing that removes the remaining infinitesimal gauge direction;
- binds a checked \(C_2\)-action in all three degrees;
- constructs the exact invariant subcomplex without identifying its cohomology with invariant
  cohomology;
- verifies a supplied plus/minus projector decomposition; and
- distinguishes a rigid problem from a non-rigid one carrying a literal tangent witness.

The example also builds and verifies central claims for the substantial results. It performs no
character-table discovery and uses no external backend.

Run it with:

```bash
uv run python examples/deformation/exact_spaces/run.py
```

The example writes no files.
